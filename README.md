# proyecto-qc

Reproducción del preprocesamiento de lecturas Illumina de *E. coli* UMB9246
(Belmonte et al., 2020, MRA 9:e00437-20; SRR11441020).

En construcción.

## Entorno

Requiere conda o mamba (por ejemplo, Miniforge). Desde la raíz del repositorio:
    mamba env create -f environment.yml
    conda activate qc-pareja1
